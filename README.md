#go-oml Golang Output Markup Language


if you need to use < or > in your text, you can use the following syntax:
```
<< >> or <<<< >>>>, etc. 
```

Creating Custom OMLs
Create a stored list of the available OMLs (or just an empty []oml if you want to only have custom OMLs)
Add a new OML to the list
Enter the list into calls that you want to use the OMLs in
